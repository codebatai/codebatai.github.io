# codebatai.github.io

Static site for Codebat Technology Inc., served from GitHub Pages at [codebat.ai](https://codebat.ai).

## Tech Stack

Plain HTML, CSS, and JavaScript. No framework, no build step.

## Local Development

Serve the directory with any static file server. For example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

Push to `main`. GitHub Pages serves the latest commit. The custom domain is configured via `CNAME` and `.nojekyll`.
